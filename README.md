# FAN TOTAL · Vive el deporte

Sitio responsive (desktop + móvil) de FAN TOTAL. Todos los botones abren WhatsApp (+52 55 1680 5237) con un mensaje que indica el botón y el evento de origen.

## Archivos
- `index.html` — página (incluye meta title, description, Open Graph, Twitter Card, canonical, favicon y datos estructurados Schema.org)
- `support.js` — runtime de la página (no borrar)
- `img/` — fotos, íconos, favicon e imagen para redes (og-fantotal.jpg)
- `robots.txt`, `sitemap.xml` — SEO

## Publicar con GitHub Pages
1. Sube todo a la raíz del repositorio.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
3. URL: `https://liliferro.github.io/fantotal/`
4. Si usas dominio propio, cambia esa URL en `index.html` (canonical, og:url, og:image, twitter:image, JSON-LD), `robots.txt` y `sitemap.xml`.
