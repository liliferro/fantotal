# FAN TOTAL · Vive el deporte

Sitio móvil de FAN TOTAL. Todos los botones abren WhatsApp (+52 55 1680 5237) con un mensaje que indica el botón y el evento de origen.

## Publicar con GitHub Pages
1. Sube `index.html` y la carpeta `img/` a la raíz del repositorio.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
3. El sitio quedará en `https://liliferro.github.io/fantotal/`.
